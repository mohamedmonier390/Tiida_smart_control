# Upload project to GitHub

1. Download and extract this ZIP on your computer.
2. Open the repository in GitHub in your browser.
3. Click **Add file → Upload files**.
4. Drag the extracted project's files and folders into the upload area (do not upload the ZIP itself).
5. Enter commit message `Add Android starter project`, then click **Commit changes**.

If GitHub web upload does not accept folders, use GitHub Desktop or Codespaces and copy the extracted folder contents into the repository.
